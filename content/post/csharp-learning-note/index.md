## 二、变量和类型

### 1.浮点数等类型：
float类型的变量赋值时，**值的末尾必须加上F**（F大小写皆可），double则不用
```
float a = 3.14F;
double pi = 3.141592;
```
值得注意的是，**C#没有.F的写法**，错误示范：
```
float a = 3.F;//这是错的
```
像这种情况F前必须有数字，比如：
```
float a = 3.0F;
```
因为浮点数误差，float与double都不适合存储金钱等敏感数字，这时候我们可以使用变量decimal：
```
decimal price = 19.99M;
```
赋值时值需要带M后缀（M大小写皆可）

### 2.布尔类型：

C#是强类型的语言，所以数字是没有布尔意义的，**不能将数字赋值给布尔变量**。

只能将**小写**的true和false赋值给布尔变量：
```
bool isSunny = false;
bool isRainy = true;
```

### 3.字符和字符串类型

使用的方式与C++基本一样

```
char a = 'A';
string s = "Hello,World!";
```
### 4.打印：

输出单一类型的变量我们只需要写**Console.WriteLine(变量名);** 即可

那么我们怎么打印混合的类型呢？

比如我们想打印出来一个算式：a+b=result，我们希望打印出来后显示出变量具体的值
```
int a = 3;
int b = 5;
int result = a + b;
```
我们希望得到的输出是3 + 5 = 8,但是如果直接在字符串里写变量名，被打印出来的就只有作为字符串的变量名本身了

这时我们可以使用占位符：

```
Console.WriteLine("{0} + {1} = {2}",a,b,result);
```
占位的数字代表后面变量的排列顺序号

这种方法因为要考虑顺序略显麻烦，我们可以用相对简单的字符串插值：
```
 Console.WriteLine($"{a} + {b} = {result}");
```
只要在字符串前面打上美元符号，就不需要使用数字占位，而可以直接在花括号内输入变量名。

### 5.var类型：

var类型的变量在赋值之后可以自动推导类型。需要注意的有两点：

1.var变量必须初始化

2.var变量的类型确定之后不能再改变

```
var i = 1;//此时i为int类型变量，之后不能再改变
var f = 2.0f;//此时f为float类型变量，之后不能再改变
```
### 6.局部变量

使用花括号可以创建一个局部作用域

```
{
            int a = 1;
            Console.WriteLine(a);
        }

        {
            int a = 3;
            Console.WriteLine(a);
        }
```
这样并不会报错

但是外面如果有同名的全局变量就不行
